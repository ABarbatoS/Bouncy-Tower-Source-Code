#Descripción
Bouncy Tower es un 2D platformer con mecánicas de parry donde el jugador juega como un mago que tiene que atravesar una torre esquivando trampas y recolectando monedas.
##Controles
A -- moverse a la izquierda
D -- moverse a la derecha
K -- parry
Espacio -- saltar
*K+Espacio -- salto alto
